7 개선 항목 요약
우선순위별 개선 항목
우선순위 화면 개선 항목 구현 힌트 태그
🔴 High 게임오버 최종 점수 + 최고기록 표시 GameCanvas.tsx의 highScore, state.score 활용 UX개선
🔴 High 전체 일시정지 기능 Matter.Runner 정지/재개 API 사용 신규
🟡 Med 타이틀 타이틀/홈 화면 추가 GamePhase에 TITLE 상태 추가 또는 라우팅 신규
🟡 Med 게임 HUD를 HTML로 분리 (캔버스 외부) renderer.ts에서 점수 렌더링 제거 → React JSX로 리팩터
🟡 Med 게임오버 신기록 배지 (조건부) score > highScore 조건 확인 UX개선
🟢 Low 게임 하단 과일 진행 바 useLocalStorage로 unlockedFruits 저장 신규
🟢 Low 신규 과일 도감 화면 별도 페이지 또는 모달 컴포넌트 신규
🟢 Low 게임오버 이번 게임 만든 과일 요약 GameState에 mergedFruits Set 추가 신규

핵심 사용자 스토리

  • 나는 게임이 끝났을 때 내 점수가 얼마인지 알고 싶다
  • 나는 실수로 게임을 나가지 않고 잠깐 멈출 수 있기를 원한다
  • 나는 수박을 만들어본 적 없는데 가능한지 알고 싶다
  • 나는 어떤 과일들이 있는지 미리 보고 싶다

기존 코드 활용 포인트

  • useLocalStorage → 과일 도감, 신기록
  • useResponsive → 반응형 레이아웃
  • GamePhase enum → 타이틀 상태 추가
  • FRUITS 배열 → 도감 데이터 소스
  • Matter.Runner → 일시정지/재개

디자인 원칙 (현재 스타일 유지)

  • 배경: #0F0F1E ~ #1A1A2E 계열
  • 폰트: Jua (레트로 8비트)
  • 강조: #f0e040 (골드), #40a0d0 (블루)
  • 위험: #FF0000 / #d04040
  • 성공: #40d080 (그린)
